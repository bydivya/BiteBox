BiteBox – Food Discovery Website

This is a simple responsive food ordering and restaurant discovery webpage created using HTML and CSS.

## Features
- Responsive navigation bar using Flexbox
- Restaurant cards using CSS Grid
- Food categories
- Hover effects
- Responsive layout for mobile, tablet and desktop
- Media queries and container queries

## Technologies Used
- HTML5
- CSS3

## Testing
The webpage was tested using Chrome DevTools in mobile, tablet and desktop screen sizes.
